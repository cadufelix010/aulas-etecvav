# 3º Bimestre — Arte Digital

## Atividade: Cartaz com várias imagens e camadas

**Tema escolhido:** Homem-Aranha  
**Alunos:** Carlos Eduardo Félix e Conrado Gazano

### Objetivo
Criar um cartaz no GIMP utilizando os recursos trabalhados em aula, com várias imagens e camadas.

### Requisitos da atividade
- Criar o cartaz no GIMP.
- Utilizar diversas imagens.
- Trabalhar com várias camadas.
- Aplicar os recursos mostrados nas aulas.
- Inserir os nomes da dupla no rodapé.
- Exportar o resultado em formato PNG.
