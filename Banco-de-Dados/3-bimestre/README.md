# 3º Bimestre — Banco de Dados

## Trabalho: Empresa Infonet

**Alunos:** Carlos Eduardo Felix da Silva e Conrado Gazano Peixoto

Atividade desenvolvida para Microsoft SQL Server / SQL Server Management Studio (SSMS).

### Conteúdos praticados
- Criação de banco de dados
- Criação de tabela
- Chave primária e campo `IDENTITY`
- Restrição `UNIQUE`
- Inserção de registros
- Atualização com `UPDATE`
- Exclusão com `DELETE`
- Consultas com `SELECT` e `WHERE`

O arquivo `atividade-infonet.sql` pode ser executado novamente, pois recria o banco `bd_infonet` antes de iniciar.
